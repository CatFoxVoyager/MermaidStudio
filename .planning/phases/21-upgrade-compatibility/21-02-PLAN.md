<objective>
Flip the rendering engine to exact-pinned mermaid 12.0.0 in one atomic, revert-safe move: remove `@mermaid-js/layout-elk`, delete its registration, rework `manualChunks` so mermaid's own ELK lazy chunk survives, and prove the Plan 01 golden baseline still holds on v12.

Purpose: this is the milestone's pivot commit. Atomicity (manifest + lockfile + code in one commit) is what makes `git revert` restore the known-good 11.17.2 + 0.2.3 pair (VAL-03's documented revert path). The chunk rework is NOT optional cleanup — without the fall-through guard, the catch-all rule force-merges mermaid's internal ELK async chunk into the eagerly-loaded mermaid-core chunk (~+500 kB gz for every user), silently violating UPG-04.
Output: app boots, tests, and production build green on exact mermaid 12.0.0 with ELK served lazily from mermaid's own chunks.
</objective>
