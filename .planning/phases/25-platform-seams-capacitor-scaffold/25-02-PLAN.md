<objective>
Build the phase's only new user-facing element: the pre-React "WebView too old" error screen (PLAT-03), injected exclusively into the native build's index.html by a `transformIndexHtml` plugin, with a boot-phase guard that distinguishes "bundle failed to parse" from "app crashed at minute 10".

Purpose: on a WebView below the `baseline-widely-available` floor the app bundle cannot parse — no React, no i18n, no Tailwind. The only honest failure mode is self-contained static markup revealed by an inline error handler; a white screen is a silent DoS. The injection lives only in the native config, keeping VAL-02 mechanically true (web index.html byte-untouched).

Output: `src/lib/platform/webviewErrorScreen.ts` (UI-SPEC-locked constants + plugin), its test file, and the native-only injection wired into `vite.config.native.ts` with build-level proof.
</objective>
