<objective>
Land the platform seam and the native build flavor: install the Capacitor 8 runtime (behind a blocking legitimacy checkpoint), create `src/lib/platform/capabilities.ts` as the single source of platform truth, gate the bootstrap surfaces in `src/main.tsx`/`src/App.tsx`, and compose `vite.config.native.ts` (WebView-compatible target, isolated `dist-native/` output, AI runtime stubs, service-worker payload drop).

This plan proves the whole architecture on the tracer slice: one runtime flag → gated bootstrap → independently built native bundle, with the web pipeline provably untouched.

Output: capabilities seam + tests, gated bootstrap, vite.config.native.ts with a green native build, Capacitor deps pinned at 8.5.2.
</objective>
